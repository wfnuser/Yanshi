# Live2D 全双工工作台

目标：本机浏览器显示 Live2D Hiyori，先播放本机生成的中文音频测试嘴形，再通过真实 Qwen-Audio-Agent Gateway 持续收发语音，用户可在播放期间插话。

实现：Live2D 官方示例模型 + Cubism Core + Pixi；wLipSync 1.3.1 的 WASM/MFCC 元音特征作为嘴形辅助，并提供音量开合对照。口型只分析实际扬声器播放图的音频，PCM 被取消时嘴形立即关闭。Hiyori 是开合与形状两个参数，不宣称达到逐音素精确唇读。

Gateway 复用已有冻结官方仓库的服务和客户端 SDK，以独立配置/数据目录启动；使用该项目已配置的 DashScope 凭据，密钥不进入前端。初版无执行后端，以语音互动为本目标。麦克风 AudioWorklet 始终独立于输出播放，Qwen 原生检测插话后清空待播放音频；同时提供手动打断。先保存本地演示和自动化验证证据，真实 API 会话按实际结果记录。

界面：冷白背景 #f5f8fc、靛蓝 #344d9d、浅蓝 #dfeafb、深蓝灰 #25324a、珊瑚 #d96d75。左侧为占主要空间的角色舞台，右侧窄列对话。系统中文无衬线字体；明确连接、静音、打断、断开按钮；诊断与素材许可折叠。

验收：模型本地加载；测试音频播放与嘴形可视；静音/取消闭嘴；真实双向 PCM 与 Qwen 回复；播放期间输入持续送达且插话能停播；错误可见；本地启动脚本与素材来源齐全。未发生的真人体验不冒充已验收。
